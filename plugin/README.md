# 人生游戏 · Lifegame

一天一屏，管四件慢功夫：**耐心、轻盈、专注、健康**。

不是待办清单，也不是打卡 App。它只做一件事：**在每天开始的时候，告诉你"今天最重要的三件事"和"你现在该干什么"**，然后让你自己做决定。

---

## 装上之后在哪找到它

- **侧栏**：DSH 左侧栏 → 「人生游戏」
- **对话里**：直接说「今天怎么样」「记一笔」「这周我做了多少」，Agent 会读写同一份数据

---

## 三个页面

### 今天

| 区块 | 内容 |
|------|------|
| 现在 | 当前时间 + 下一件规定事项 + 一个「开始」按钮 |
| 专注 | 番茄计时（默认 25 分钟，做完即止，不强制休息） |
| 规定事项 | 每天固定的三件：冥想 / 运动 / 写一段话。标题和时间都能改 |
| 今天要做 | 自由待办。回车换行、写好再点「加」；点文字就能改 |
| 稍后深度阅读 | 贴一个链接，后台解析出摘要、纲要和建议阅读时长 |
| 它在看着 | 三条从你真实数据里算出来的事实（还剩几件 / 日落时间 / 断了几天） |

### 本周

| 区块 | 内容 |
|------|------|
| Inbox | 这周冒出来的所有事。可以排期到某一天 |
| 便签 | 随手写的，只属于这一周 |
| 这一周 | 七天日历，每天可以直接加待办 |
| 本周推荐 | 根据你的目标、收藏和天气给三条建议，可以一键「安排」到某天 |

### 我

| 区块 | 内容 |
|------|------|
| 九十天 | 13 周 × 7 天的活跃格，按当天完成量分四档蓝 |
| 统计 | 活跃度 + 近 30 天完成柱状图 + 近 14 天专注柱状图 + 两个达成率环 |
| 你定义的远方 | 短期 / 长期目标，可以「拆解」成步骤，再「放到本周」或「放到今天」 |
| 每天的规矩 | 规定事项的模板：改标题和时间，之后每天都按这个来 |
| 收集仓库 | 书 / 电影 / 文章 / 图片 / 技能。图片可以直接拖进来或粘贴 |

## 数据在哪

**全部存在本机**：

```
$DSH_HOME/lifegame/
├── db.json          ← 唯一真相源
├── db.json.bak      ← 上一次的备份
└── media/           ← 你收藏的图片
```

**不上传任何服务器。** 卸载插件不会删数据，想彻底清除就删掉这个目录。

## 它会用到什么

| 用途 | 说明 |
|------|------|
| **大概位置** | 拉天气用。默认「杭州 · 余杭」，可以在页面上改 |
| **你的模型** | 推荐、目标拆解、每日一句——**只有你点了才会调用**，不会后台偷偷跑 |
| **本地文件** | 收藏的图片落盘到 `media/`，单张上限 8MB |

关掉插件后：侧栏入口消失，十个工具不可用，但数据还在。

---

## 十个 Agent 工具

Agent 通过它们读写同一份数据，所以你说「把那个目标拆一下」，它真的会改你的数据：

| 工具 | 用途 |
|------|------|
| `lifegame_today` | 今天的完整状态 |
| `lifegame_update` | 勾完成 / 撤回 / 写一句 |
| `lifegame_todo` | 自由待办增删改 |
| `lifegame_timer` | 番茄开始 / 结束 / 状态 |
| `lifegame_inspiration` | 今日一句 |
| `lifegame_week` | 本周状态 + 推荐 |
| `lifegame_readlater` | 稍后阅读 |
| `lifegame_goals` | 目标与步骤 |
| `lifegame_collect` | 收集仓库 |

## 已知限制

- **只有 Web 面板**：手机端（DSH Go）的原生插槽还没有实现
- **没有测试**：这是 1.0.0，主要路径走过，边界情况可能有 bug
- **数据不跨设备**：存在本机，换机器要手动搬 `db.json`
- **番茄不做长时间记录**：只记时长和一句标签，不做统计报表

---

## 卸载

在插件管理里移除 `dsh-lifegame` 即可。数据不会自动删除。
