人生游戏
它是什么 长什么样 怎么装 GitHub

一天一屏，
管四件慢功夫。

耐心、轻盈、专注、健康。不是待办清单，也不是打卡 App。 它只做一件事：每天开始的时候，告诉你今天最重要的三件事和现在该干什么，然后你自己决定。

装 dsh-lifegame DSH → 插件 → 添加插件
DeepSeek Harness 插件 数据只存本机 MIT 开源

Three screens

三页，一天、一周、一段日子

从「现在该干什么」到「这半年过得怎么样」，中间不需要跳到别的工具。

今天

TODAY

顶部先告诉你现在是几点、下一件规定的事是什么，一个按钮就能开始。

下面三件每天固定的事：冥想、运动、写一段话。标题和时间都能改。

右边的「它在看着」会说三句真话——还剩几件、几点日落、断了几天。

WEEK

Install

三步装好

需要一个已经装好的 DeepSeek Harness（0.2.2 或更新）。

  1. 打开插件页

    在 DSH 左侧栏点「插件」，找到「添加插件」。

  2. 填包名

    输入 dsh-lifegame，确认。它会从 npm 下载，几秒钟。

  3. 重启，点侧栏

    重启 DSH，左侧栏会多一个「人生游戏」。第一次打开自带示例数据，看一眼就懂。

Privacy

数据在你自己电脑上

没有账号，没有云同步，没有「我们可能会…」。

只写本机 所有记录存在 $DSH_HOME/lifegame/db.json，不上传任何服务器。
自动备份 每次启动前会留一份上一版，万一文件坏了还能捞回来。
模型只在你点的时候调 推荐、目标拆解、每日一句都要你主动点，不会后台偷偷跑。
卸载不删数据 移除插件后数据还在。想彻底清掉，删掉那个目录就行。
